# SUSerchingbooking

南科大致诚大会议室预约导出与飞书普通电子表格同步工具，运行于 Windows 本机。每天北京时间 05:00 更新当天预约，错过后可在登录电脑时补更。本项目为个人工具，与学校及飞书无隶属关系。

## 唯一入口

双击根目录 **预约管理.cmd**，所有操作都在同一个菜单中完成。

| 菜单 | 用途 |
| --- | --- |
| 1 首次配置 / 继续未完成的配置 | 自动衔接组件准备、账号保存、学校登录核对、飞书连接、当天更新与定时任务安装；跳过有效步骤，已有任务保留 |
| 2 一键更新 | 手动刷新今天的预约，仍遵守次数和间隔限制 |
| 3 查看更新状态 | 查看本地保存的学校导出、飞书更新及错误记录 |
| 4 打开日志文件夹 | 用记事本查看 `logs/YYYY-MM-DD.log` |
| 5 高级维护 | 修改凭据、重新登录、连接飞书、安装或移除自动任务、准备组件、生成演示 |
| 0 退出 | 关闭菜单，已安装的 Windows 自动任务继续工作 |

旧的独立 CMD 已删除。向导在取消、失败、冷却或验证未完成时停止，不会继续执行后续步骤。处理提示后再次选择 1 即可；不会自动清除请求次数限制。

## 首次使用

1. 准备 Windows、Python 3.10+（含 tkinter，安装时加入 PATH）和 Microsoft Edge。Python 3.13 已用于离线验证。
2. 下载代码并放在固定目录。凭据与自动任务按项目路径隔离，配置后不要随意移动目录。
3. 按 [飞书配置指引](docs/飞书配置指引.md) 创建并授权飞书自建应用，准备符合下方布局的普通电子表格。
4. 打开 **预约管理.cmd**，选择 **1**。已有浏览器组件会跳过安装；缺少组件时在 `.venv` 中安装，使用本机 Edge。
5. 按窗口提示保存学校账号和飞书应用凭据，填写自己的飞书 `/wiki/` 链接；正常登录学校、查看致诚大会议室当天预约并核对时间、条数和状态。需要验证码时由本人完成。
6. 向导继续连接飞书、更新并读回核对，最后安装自动任务。任何一步失败都会停在该步骤。

校园账号密码、学校会话和飞书应用密钥保存在当前 Windows 用户的凭据管理器。程序不创建、取消或修改学校预约，也不关闭或更改代理设置。

## 表格布局与更新规则

工作表固定为 **Sheet1**，至少 26 行、3 列。

| 位置 | 内容或行为 |
| --- | --- |
| A2:A9 | 从 `8:30-9:00` 到 `12:00-12:30`，每行半小时 |
| A11:A26 | 从 `14:00-14:30` 到 `21:30-22:00`，每行半小时 |
| B2:B9、B11:B26 | 学校会议与时间格重叠即标记“会议占用”，包括审批中的预约 |
| C2 | 更新当天日期 `YYYY-MM-DD`；初次连接时可为空或填写可识别日期 |
| 第 10 行及其他单元格 | 保持原样 |

**跨天首次更新会清空上述 B 列区域内前一天的全部内容，包括手填预约，再写入当天会议。** C2 为空的首次更新也会清空这些区域。当天再次更新保留非冲突手填内容，会议重叠时直接覆盖，不备份手填原文。

学校查询失败不会当作零预约，不清空表格。飞书写入后必须读回核对才记录完成。详细运行方式与故障处理见 [使用说明](docs/使用说明.md)。

## 定时与访问限制

- 北京时间 05:00 更新；默认需要已登录 Windows，锁屏可运行，错过后登录约两分钟补更。
- 不强制唤醒关机或睡眠中的电脑。补更只读取当天，获取的是实际运行时的预约快照。
- 每 10 分钟检查本地状态，当天完整更新成功后不重复访问学校和飞书。
- 学校独立查询每天最多 2 次，间隔至少 10 分钟；自动登录每天最多提交 1 次。手动更新也遵守限制。
- 首次配置中正常操作网页产生的请求不计入脚本预算，请避免反复刷新。
- 同一表格仅启用一台自动更新电脑，当前没有跨电脑协调机制。

## 目录结构

```text
预约管理.cmd             唯一双击入口
README.md                快速上手
bookpiano/               当前版本的程序源码
scripts/                 菜单启动、定时任务及诊断工具
tests/                   离线测试，使用合成数据
docs/                    使用说明和飞书配置指引
.github/workflows/       GitHub 自动测试
requirements-login.txt   浏览器组件依赖
```

以下内容仅存在本机，不提交 GitHub：

| 内容 | 用途 |
| --- | --- |
| `.venv/` | 本机运行环境 |
| `config.json`、`feishu.json` | 学校查询和个人表格设置 |
| `*-state.json`、`state.json`、`latest.json` 等 | 登录、限流、成功更新和中断恢复记录 |
| `data/` | 预约历史导出；已有旧版表格备份归档至 `data/legacy-feishu-backups/` |
| `logs/` | 每日日志和诊断记录 |
| `查看预约.html` | 最近成功预约的离线查看页 |

仓库不包含账号密钥、个人表格地址或真实预约。不要删除本机状态文件来绕过限流。更换电脑时重新下载、配置并验证，新电脑启用前在旧电脑通过高级维护移除自动任务。

## 开发验证

在仓库根目录执行：

```powershell
python -m unittest discover -s tests -v
```

测试不访问学校或真实飞书，不需要账号。离线通过不代表账号、网络和文档授权已验证，实际使用仍需完成配置向导。
