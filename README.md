# SUSerchingbooking

南科大致诚大会议室预约导出与飞书课表同步工具，运行于 Windows 本机。

每天北京时间 05:00 获取当天预约，保存 JSON、CSV 和离线 HTML，并将会议占用时段写入飞书普通电子表格。错过定时运行后可在登录电脑时补更，也支持手动更新。本项目为个人工具，与学校及飞书无隶属关系。

## 更新规则

| 项目 | 行为 |
| --- | --- |
| 工作表 | 只更新 `Sheet1` |
| 预约区域 | `B2:B9`、`B11:B26` |
| 占用标记 | 学校会议与半小时时段有重叠即填入“会议占用”，包括审批中的预约 |
| 日期 | `C2` 写入当天日期 |
| 跨天更新 | 清空上述预约区域内前一天所有内容，包括手填预约，再写入当天会议 |
| 当天再次更新 | 保留非冲突手填内容；会议重叠时直接覆盖，不备份手填原文 |
| 请求失败 | 不把失败当作零预约；学校查询失败时保留表格原内容 |

程序不创建、取消或修改学校预约。飞书写入后需读回核对，成功后才记录当天已完成。

## 首次安装

需要 Windows、Python 3.10+（包含 tkinter，安装时加入 PATH）、Microsoft Edge，以及有权访问预约系统的校园账号。Python 3.13 已用于本地离线验证。

1. 下载仓库 ZIP 并解压，或克隆仓库。选定固定目录后再配置；凭据和定时任务按目录隔离。
2. 双击 **准备登录组件.cmd**，创建 `.venv` 并安装 Playwright；使用已安装的 Edge，无需另行下载 Chromium。
3. 按 [飞书配置指引](飞书配置指引.md) 创建自建应用、发布权限，并授予目标表格编辑权限。表格需符合下方布局。
4. 双击 **配置账号与飞书.cmd**，填写校园账号、飞书应用凭据和自己的 `/wiki/` 链接。凭据保存在当前 Windows 用户的凭据管理器。
5. 双击 **首次配置.cmd**，正常登录并查看致诚大会议室当天预约，按窗口提示核对结果。程序从正常页面请求学习有效接口，不轮流尝试接口。
6. 双击 **连接飞书表格.cmd**，读取并验证目标 Sheet1。
7. 双击 **手动更新.cmd**，完成一次实际查询、写入和读回核对。
8. 双击 **安装自动更新.cmd**。只有前述实际验证通过后，才允许安装定时任务。

验证码、登录策略和接口变化可能需要重新进行人工配置。不要通过直接修改验证标记跳过核对。

## 目标表格布局

创建普通电子表格，工作表命名为 `Sheet1`，至少 26 行、3 列。程序校验 A 列时间，布局不符时停止写入。

| 行 | A 列 | B 列 | C 列 |
| --- | --- | --- | --- |
| 1 | 可自定义标题 | 可自定义标题 | 可自定义标题 |
| 2–9 | 从 `8:30-9:00` 到 `12:00-12:30`，每行半小时 | 预约区域 | C2 为日期，其余不修改 |
| 10 | 可自定义午休提示 | 不修改 | 不修改 |
| 11–26 | 从 `14:00-14:30` 到 `21:30-22:00`，每行半小时 | 预约区域 | 不修改 |

初次使用的 C2 可为空或填写 `YYYY-MM-DD`；为空时首次更新将清空预约区域。其他单元格和工作表不会被自动更新。

## 日常使用与日志

- **手动更新.cmd**：立即尝试更新，仍遵守每天查询次数及间隔限制。
- **检查运行状态.cmd**：查看本地记录的导出和飞书同步结果，不访问网站。
- **查看预约.html**：首次成功导出后生成，可离线打开。
- **logs/YYYY-MM-DD.log**：当天运行日志，例如 `logs/2026-09-29.log`，用记事本打开即可。
- **移除自动更新.cmd**：移除当前目录对应的任务，保留配置与数据。

预约查询每天最多 2 次，间隔至少 10 分钟；自动校园登录每天最多提交 1 次。定时任务每 10 分钟检查本地状态，当天完整更新后直接退出，不重复访问两端。首次配置时正常网页操作产生的请求不在脚本预算内，请避免反复刷新。

默认在登录 Windows 后运行，锁屏可用，错过 05:00 后登录约两分钟补更。关机或睡眠时不会强制唤醒；补更获取的是运行时的当天快照。具体运行方式见 [使用说明](使用说明.md)。

## 迁移与隐私

新电脑下载代码，重新准备登录组件、输入凭据并完成首次验证和任务安装。不要复制旧 `.venv` 或依赖旧电脑的凭据。启用新电脑前，在旧电脑运行 **移除自动更新.cmd**。

同一表格仅启用一台自动更新电脑；当前只有本机进程锁，没有跨电脑协调，两台同时写入可能互相覆盖。

仓库不包含校园账号、密码、应用密钥、个人表格地址、会话令牌、真实预约、日志或本地状态。运行后产生的这些文件已列入 `.gitignore`。分享故障信息时也应去除个人预约和标识。

## 项目结构与验证

```text
bookpiano/        查询、登录、本地导出、飞书同步及配置界面
scripts/          Windows 启动与任务计划脚本、诊断工具
tests/            离线单元与模块集成测试，使用合成数据
*.cmd             中文双击入口
requirements-login.txt
```

在仓库根目录运行：

```powershell
python -m unittest discover -s tests -v
```

测试不访问学校或真实飞书，不需要账号。离线通过不代表新机器的账号、网络和文档授权已验证，仍需完成首次安装流程。
