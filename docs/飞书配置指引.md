# 飞书应用配置：致诚大会议室自动更新

本工具使用企业自建应用更新你提供的普通电子表格。校园密码和飞书 App Secret 都只在本机配置窗口填写，不要发送到聊天中。

## 1. 创建应用

1. 打开 [飞书开发者后台](https://open.feishu.cn/app)，登录能管理目标表格的飞书账号。
2. 选择目标表格所属的组织，点击 **创建企业自建应用**。
3. 应用名称填 **致诚会议室自动更新**；描述可填“每天将致诚大会议室预约同步到指定电子表格”。按页面要求设置图标。
4. 在“添加应用能力”中启用 **机器人**，用于后面将应用添加为文档协作者。

本工具不接收消息，不需要配置事件订阅、回调地址或个人 OAuth 重定向地址。

## 2. 开通接口权限

进入应用的 **权限管理 → 开通权限**，在“应用身份”的权限中按下面的权限码搜索并开通：

| 权限码 | 用途 |
|---|---|
| `sheets:spreadsheet` | 读取、编辑 Sheet1 的预约区域和日期 |
| `wiki:wiki:readonly` | 将你提供的 `/wiki/` 链接解析为实际电子表格 |

中文权限名称可能显示为“查看、评论、编辑和管理电子表格”“查看知识库”；以权限码为准。无需开通多维表格、通讯录或消息发送权限。

注意区分 **应用身份权限** 和 **用户身份权限**：本工具用 App ID、App Secret 获取应用身份，只有用户身份下开通权限不能满足这个脚本。开通后还需发布包含新权限的版本，若有审批，要等审批通过。

参考：[飞书电子表格自动化示例](https://open.feishu.cn/community/articles/7302287257225445404?lang=zh-CN)、[知识库权限示例](https://open.feishu.cn/community/articles/7293415563448238084?lang=zh-CN)。

## 3. 发布并使权限生效

1. 进入 **版本管理与发布 → 创建版本**。
2. 版本号可填 `1.0.0`，更新说明填“会议室预约自动更新”。
3. 应用可用范围至少包含你及目标电子表格的所有者。
4. 提交发布。如果组织要求管理员审批，请等审批通过，并确认应用已经发布或启用。

以后新增权限也需按后台提示更新版本并发布。只保存开发配置，可能还不能通过正式接口使用。

## 4. 授予这份表格的编辑权限

1. 打开 你自己的目标电子表格。
2. 从页面右上角 **… → 更多 → 添加文档应用** 进入。
3. 搜索 **致诚会议室自动更新**，权限选择 **可编辑**，然后添加。

“所有人可编辑”不能替代这一步。应用的接口权限和具体文档的协作权限需要同时具备。[飞书官方授权说明](https://www.feishu.cn/content/383321056779)

如果没有“添加文档应用”入口，请让表格所有者或知识库管理员操作。若搜不到应用，先检查组织是否一致、机器人能力是否启用、正式版本是否发布，以及所有者是否在可用范围内。若连接提示知识库权限不足，请管理员核对该知识库节点对应用的访问权限，不必先给整个知识库的管理权限。

## 5. 把凭据保存到本机

1. 回到应用后台的 **凭证与基础信息**，找到 **App ID** 和 **App Secret**。
2. 在解压后的项目目录中双击 **预约管理 → 5 高级维护 → 1 修改账号与飞书配置**。
3. 填写校园用户名、校园密码、飞书 App ID、App Secret 和自己的飞书知识库链接（`https://你的组织.feishu.cn/wiki/节点编号`）。
4. 目标工作表固定为 **Sheet1**，勾选本机保存用途确认并保存。

保存位置是当前 Windows 用户的凭据管理器。项目里的 JSON 文件只存非敏感设置，不存密码或 App Secret。本窗口保存时不访问学校或飞书。

## 6. 完成一次实际验证

按顺序运行这些入口：

| 顺序 | 菜单入口 | 成功的表现 |
|---|---|---|
| 1 | 菜单 5 → 2：登录核对 | 正常登录学校，在网页选择致诚大会议室、今天，核对程序观察到的预约；一致后输入 `y` |
| 2 | 菜单 5 → 3：连接飞书 | 成功识别普通电子表格，核对现有 Sheet1 时间格与 C2 日期 |
| 3 | 菜单 2：一键更新 | 显示预约已写入飞书且读回核对通过 |
| 4 | 菜单 5 → 4：自动任务 | 实际验证通过后，安装每天 05:00 及开机/登录补更任务 |

首次配置只观察你正常打开页面产生的预约请求，不自动轮流尝试接口。观察不到有效数据时会留下不含密码和完整响应的诊断文件；请不要反复刷新网页。

“连接飞书表格”只读取并核对，不创建工作表。“手动更新”才会用当天真实数据更新 Sheet1。配置连接的重复尝试间隔为 10 分钟。

## 表格中的自动更新范围

脚本只使用 **Sheet1 的 B2:B9、B11:B26 和 C2**。学校会议与半小时时间格重叠时，B 列填入“会议占用”，审批中的预约也参与标记。跨天首次更新清除两段区域内上一天全部内容，包括手填预约。当天手动更新保留非重叠手填内容，重叠时直接覆盖，不做内容备份。C2 写入当天日期 YYYY-MM-DD。其他单元格及工作表保持原样。

写入后重新读取核对。学校查询失败时保留飞书原内容；飞书写入失败时保留本地当天导出并只重试飞书。网络超时可能发生在服务器已经写入之后，因此只有读回核对成功才记作当天完成。中断恢复记录只保存原值哈希和目标标记，不保存手填原文。

## 常见提示

| 提示 | 处理 |
|---|---|
| 应用凭据无效 | 在“凭证与基础信息”重新复制，并在本机配置窗口保存 |
| 接口权限不足 | 核对上述两项应用身份权限，确认版本已发布 |
| HTTP 400 / 99991672，读取工作表列表失败 | App ID、App Secret 和知识库解析可以已成功，但电子表格权限尚未生效。开通应用身份的 `sheets:spreadsheet` 并发布、完成审批；不需要把错误提示中列出的所有 `drive:*` 权限都开通 |
| 无权访问表格或节点 | 核对“添加文档应用 → 可编辑”和知识库节点权限 |
| Sheet1 时间与已确认布局不符 | 恢复 A 列的半小时时间格；为防止错行，程序会停止写入 |
| C2 不是可识别日期 | 将 C2 日期写成 YYYY-MM-DD，再连接 |
| 距上次不足 10 分钟 | 等待后再运行，修改权限和查看状态不受限制 |
| 校园登录未完成 | 运行首次配置处理验证码或检查账号；自动登录每天最多提交一次 |

目前程序的实际可用性仍需你保存凭据后完成第 6 步验证。离线测试通过不等于学校接口和这份飞书表格已经连接成功。
